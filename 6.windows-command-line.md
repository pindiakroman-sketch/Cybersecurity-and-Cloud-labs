## 1. Executive Summary

This lab focused on using the Windows Command Prompt (CMD) to investigate a Windows system without relying on its graphical interface. The exercises covered filesystem navigation, file discovery, hidden file identification, file content inspection, and basic system and network enumeration.

## 2. Technical Investigation

### 2.1 Filesystem Navigation

CMD allows users to navigate directories and inspect filesystem contents directly from the terminal.

```bat
cd
dir
cd C:\Windows
```

- `cd` displays or changes the current directory.
- `dir` lists files and directories in the current location.
- `cd C:\Windows` changes the working directory to the Windows system directory.

### 2.2 File Discovery and Hidden Files

File discovery is useful when locating configuration files, scripts, and other artifacts during system investigations.

```bat
dir /s /b C:\example\filename.txt
```

This searches recursively under the specified directory for matching paths. The example path and filename are placeholders.

To display hidden files and directories:

```bat
dir /a
```

The `/a` option includes files with attributes such as Hidden and System in the directory listing.

### 2.3 File Content Inspection

Text-based files can be inspected directly through CMD without opening a graphical editor.

```bat
type C:\path\to\file.txt
```

For longer files, output can be paginated:

```bat
type C:\path\to\file.txt | more
```

Inspecting configuration files and scripts can help identify relevant system settings or suspicious content. Sensitive data should be handled carefully.

### 2.4 System Enumeration

Basic system commands provide information about the operating system and host configuration.

```bat
systeminfo
hostname
whoami
```

- `systeminfo` displays detailed operating system and hardware-related information.
- `hostname` displays the computer name.
- `whoami` identifies the current user account.

### 2.5 Network Information Gathering

Network enumeration helps establish the host's network configuration and identify connectivity-related information.

```bat
ipconfig /all
```

This displays network adapter configuration, including IP addresses, DNS settings, and other TCP/IP details.

Network information can support troubleshooting and initial security investigations. Actual findings must be validated against the environment being examined.

## 4. Security Recommendations

1. **Investigate Hidden Files Carefully:** Hidden attributes do not indicate malicious activity by themselves. Validate suspicious files using their paths, metadata, contents, and available security telemetry.
2. **Apply Least Privilege:** Restrict administrative permissions and limit access to sensitive files and system configuration.
3. **Correlate System Findings:** When investigating a Windows endpoint, correlate command-line observations with endpoint security alerts, Windows Event Logs, and network telemetry where available.

## 5. Key Takeaways

Windows CMD provides a practical way to enumerate files, inspect system information, and gather network configuration details without relying on the GUI. These skills support troubleshooting, endpoint investigation, and future SOC workflows involving Windows Event Logs, PowerShell, and endpoint detection tools.
