# Windows Basics | System Administration & Security

## Lab Overview

- **Platform:** TryHackMe
- **Environment:** Windows Server 2019
- **Category:** Windows Administration / Security Fundamentals
- **Difficulty:** Beginner
- **Focus:** System configuration, application management, file operations, security scanning, Windows security controls

---

## 1. Executive Summary

This lab introduced core Windows administration and security concepts through a practical exercise using Windows Server 2019. The tasks involved managing files, installing applications, inspecting system configuration, and performing security scans in a workstation environment.

## 2. Technical Investigation

### 2.1 System Configuration and Administration

Explored Windows system configuration and administrative interfaces to understand how system properties, installed applications, and operating system settings are managed.

### 2.2 File and Application Management

Practiced working with files and directories and installing applications in a Windows environment. These operations are relevant to software inventory, system maintenance, and investigating potentially unauthorized files or applications.

### 2.3 Security Controls

Reviewed built-in Windows security components and their roles in protecting the operating system.

Key components include:

- **Windows Security:** Central interface for reviewing security status and managing built-in protection features.
- **Microsoft Defender Antivirus:** Helps detect and respond to malware and other threats.
- **Windows Defender Firewall:** Controls inbound and outbound network traffic according to configured firewall rules.
- **Windows Update:** Delivers operating system and security updates.

### 2.4 System Monitoring

Reviewed the role of Task Manager in monitoring running processes, resource consumption, and application activity.

Process and resource monitoring provides useful context when investigating unexpected system behavior, suspicious applications, or performance issues.

## 3. Findings

- Identified key Windows administration interfaces and security components.
- Practiced file operations and application installation in a Windows Server 2019 environment.
- Examined the purpose of built-in antivirus and firewall protections.
- Reviewed system monitoring capabilities relevant to basic troubleshooting and security investigations.

**Evidence limitation:** Specific command outputs, scan results, detected threats, firewall rule changes, and system configuration values were not recorded in the available notes.

## 4. Security Recommendations

1. **Patch Management:** Apply security updates regularly and verify that supported operating systems receive current security patches.
2. **Endpoint Protection:** Maintain active antivirus protection and investigate security alerts rather than relying solely on successful scan completion.
3. **Application and Access Control:** Restrict software installation and administrative privileges to authorized users. Monitor unexpected applications and suspicious processes.

## 5. Key Takeaways

This lab established a foundation in Windows system administration, endpoint security, and system monitoring. These concepts support further learning in Windows command-line administration, event log analysis, endpoint detection, and SOC operations.
