# 🌐 Wireshark Basics: Lab Notes & Practical Analysis

Notes and practical walkthroughs covering the foundational concepts of packet analysis, navigation, and display filtering using **Wireshark** on the `Exercise.pcapng` capture file.

---

## 🛠️ Part 1: Core Concepts & Capabilities Learnt

### 1. Packet Dissection & Navigation
* **Dissection Layers:** Understood how Wireshark breaks down packets layer-by-layer matching the TCP/IP or OSI model (Data Link, Network, Transport, and Application layers).
* **Navigation:** Mastered jump actions using `Ctrl + G` (Go to Packet) to isolate specific traffic events instantly by their frame number.

### 2. GUI Filtering Tricks ("If you can click it, you can filter it")
* **Apply as Filter:** Right-clicking any packet detail field to immediately filter the entire capture by that specific attribute.
* **Prepare as Filter:** Staging a query in the filter bar without executing it immediately, allowing complex logical strings (`and`/`or`) to be built manually.
* **Apply as Column:** Moving a deeply nested packet field (like an HTTP User-Agent or custom header) into the main packet list pane to visually track it across the whole capture.
* **Conversation Filtering & Colourisation:** Grouping and color-coding all interconnected packets between specific IP addresses and ports to isolate specific sessions without losing the surrounding context.

### 3. Stream Reconstruction
* **Follow Stream:** Used **Follow -> TCP/HTTP Stream** to stitch fractional network fragments back into raw, application-level text.
* **Traffic Indicators:** Client-to-server traffic is highlighted in **Red**, and server-to-client responses are highlighted in **Blue** (critical for checking unencrypted payloads like JSON data or cleartext credentials).
